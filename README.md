# 🍕 Mania Pizza

Cardápio digital interativo para Mania Pizza.

## 📋 Descrição

Site responsivo com cardápio completo da Mania Pizza, permitindo visualizar produtos, preços e fazer pedidos online.

## ✨ Funcionalidades

- 🍕 Cardápio completo com categorias
- 🖼️ Imagens dos produtos
- 💰 Exibição de preços
- 📱 Design responsivo
- 🛒 Sistema de carrinho
- 📞 Contato direto

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript Vanilla

## 📦 Como Usar

1. Clone o repositório
```bash
git clone https://github.com/blinkmunoz/mania-pizza.git
```

2. Abra o arquivo `index.html` no navegador

3. Navegue pelo cardápio

## 📁 Estrutura

```
mania-pizza/
├── index.html       # Página principal
├── css/
│   └── style.css    # Estilos
├── js/
│   └── script.js    # Scripts
└── images/          # Imagens dos produtos
```
